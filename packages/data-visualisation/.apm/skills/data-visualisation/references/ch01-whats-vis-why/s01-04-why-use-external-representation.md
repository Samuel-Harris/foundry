# 1.4 Why Use an External Representation?

## Principle

<!-- verbatim p.31 -->
> External representations augment human capacity by allowing us to surpass the limitations of our own internal cognition and memory.
<!-- /verbatim -->

## Offloading to perception

Vis lets people offload internal cognition and memory to the perceptual system, using carefully designed images as external representations, also called external memory [p.31]. External representations can be physical objects such as an abacus or a knotted string, but the book focuses on what can be shown on the two-dimensional display surface of a computer screen [p.31].

## How diagrams help, and how they fail

Diagrams can be designed to support perceptual inferences, which humans make very easily [p.31].

<!-- verbatim p.31 -->
> The advantages of diagrams as external memory is that information can be organized by spatial location, offering the possibility of accelerating both search and recognition.
<!-- /verbatim -->

- **Search** speeds up when all the items needed for a specific problem-solving inference are grouped at the same location [p.31].
- **Recognition** improves when all the relevant information about one item is grouped in the same location, avoiding the need to match remembered symbolic labels [p.31].
- **Failure.** A nonoptimal diagram may group irrelevant information together, or support perceptual inferences that are not useful for the intended problem-solving process [p.31].
