# 1.9 Why Focus on Tasks?

## Principle

<!-- verbatim p.36 -->
> A tool that serves well for one task can be poorly suited for another, for exactly the same dataset.
<!-- /verbatim -->

The users' task is as important a constraint for a vis designer as the kind of data they have [p.36].

## Abstract tasks

Reframing the task from a domain-specific form into an abstract one lets you consider the similarities and differences between what people need across many real-world contexts [p.36].

- A vis tool can support presentation, discovery or enjoyment of information, or producing more information for later use [p.36].
- For discovery, vis can generate new hypotheses, as when exploring a completely unfamiliar dataset, or confirm existing hypotheses about a dataset already partly understood [p.36].
