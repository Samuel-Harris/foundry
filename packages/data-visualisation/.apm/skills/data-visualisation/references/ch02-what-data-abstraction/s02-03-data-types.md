# 2.3 Data Types

## The five basic data types

Figure 2.2 shows the five basic data types: items, attributes, links, positions and grids [p.48].

### Attribute

<!-- verbatim p.48 -->
> An attribute is some specific property that can be measured, observed, or logged.
<!-- /verbatim -->

Examples are salary, price, number of sales, protein expression levels and temperature [p.48]. Synonyms are variable and data dimension; the book reserves "dimension" for the visual channels of spatial position [p.48].

### Item

An item is an individual entity that is discrete, such as a row in a simple table or a node in a network; examples are people, stocks, coffee shops, genes and cities [pp.48-49].

### Link

<!-- verbatim p.49 -->
> A link is a relationship between items, typically within a network.
<!-- /verbatim -->

### Grid

<!-- verbatim p.49 -->
> A grid specifies the strategy for sampling continuous data in terms of both geometric and topological relationships between its cells.
<!-- /verbatim -->

### Position

<!-- verbatim p.49 -->
> A position is spatial data, providing a location in two-dimensional (2D) or three-dimensional (3D) space.
<!-- /verbatim -->

Examples are a latitude–longitude pair on the Earth's surface, or three numbers locating a point in the region measured by a medical scanner [p.49].
