# 3.4 Actions

Actions are the verbs of a task, at three levels: analyze (consume existing data, or also produce additional data), search (whether the target and its location are known) and query (identify one target, compare some, or summarize all) [p.70]. The three levels are independent of each other, and it is usually useful to describe an action at all three [p.70].

## Children

- [3.4.1 Analyze](s03-04-01-analyze.md) · ~834 words. **Use when** classifying the top-level purpose as consuming existing information: discover (generate or verify a hypothesis about something not yet known), present (communicate something already understood to an audience) or enjoy (casual, curiosity-driven use) [pp.70-74]
- [3.4.2 Produce](s03-04-02-produce.md) · ~1,015 words. **Use when** the user or designer generates new material: annotate existing elements, record persistent artifacts such as a graphical history, or derive new attributes or a new dataset type, for example a difference attribute to plot directly [pp.74-78]
- [3.4.3 Search](s03-04-03-search.md) · ~564 words. **Use when** deciding how the user finds elements of interest, by whether the target's identity and location are known: lookup (both), locate (target only), browse (location only), explore (neither, often from an overview) [pp.78-79]
- [3.4.4 Query](s03-04-04-query.md) · ~399 words. **Use when** the targets are found and the question is how many are under consideration: identify one, compare multiple, or summarize (overview) all [pp.79-80]

## Disambiguation

- **Analyze vs Produce.** Produce is the second branch of the analyze level: Analyze covers using vis only to consume existing information, Produce covers also generating new material [p.70] [p.74].
- **Search vs Query.** Search is about finding targets, classified by what is known about their identity and location; query is what the user does with targets once found, scoped as one, some or all [p.78] [p.79]. Identify depends on the search type: after lookup or locate it returns characteristics, after browse or explore it returns references [pp.79-80].
- **Analyze vs Search.** Discover (under Analyze) is a consume goal, finding new knowledge; explore (under Search) is a search type in which neither target nor location is known. The book places them at different levels [p.72] [p.79].
