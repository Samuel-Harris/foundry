# 6.3.6 Tilted Text Isn't Legibile

"Legibile" is the book's spelling in this heading; Figure 6.1 lists the same point as "Tilted Text Isn't Legible" [p.141] [p.149].

## The problem

<!-- verbatim p.149 -->
> Another problem with the use of 3D is dramatically impaired text legibility with most standard graphics packages that use current display technology [Grossman et al. 07].
<!-- /verbatim -->

- **2D text is tuned.** Fonts are designed for the pixel grid of a 2D display, so characters as small as nine pixels high are easily readable [p.149].
- **3D text is fast but poor.** Hardware acceleration renders text at arbitrary 3D orientations quickly, but usually not well [p.149].
- **Any tilt hurts.** As soon as a label is tilted off the image plane it typically becomes blocky and jaggy [p.149].
- **Outlook.** More careful rendering and displays of many hundreds of dots per inch may solve this in future, but legibility is a major problem today [p.149].
