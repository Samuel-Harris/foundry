# 8.5.4 Feature Flow

## Explicitly derived features

Feature flow idioms use global computations across the entire vector field to explicitly locate all instances of specific structures of interest, such as critical points, vortices and shock waves [pp.218-219]. An alternative name is topological flow vis [p.219].

- **Goal.** Partition the field into subregions where the qualitative behaviour is similar [p.219].
- **Encoding.** The derived data is then directly encoded with one of the earlier flow idioms, as geometry or as a glyph per feature [p.219].
- **Contrast with the other families.** Glyph, geometric and texture idioms help users infer that these structures exist, but do not necessarily show them directly [p.219].
- **Main challenge.** The algorithmic problem of locating the structures efficiently and correctly [p.219].
