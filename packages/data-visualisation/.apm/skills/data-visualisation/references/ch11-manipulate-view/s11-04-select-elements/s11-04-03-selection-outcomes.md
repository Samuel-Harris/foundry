# 11.4.3 Selection Outcomes

## Selection as the first step

<!-- verbatim p.279 -->
> Selection is often a first step in a multistage sequence, allowing the user to indicate specific elements that should be the target of the next action.
<!-- /verbatim -->

Sometimes the outcome of selection is further action beyond highlighting: the output of a select action is often the input to the next action [p.279]. Chained sequences of tasks are discussed in Sections 1.14 and 3.7 [p.279].

## What a selection can feed

Nearly all other major design choices for constructing idioms can take a selected set as input [p.279]. The book's examples:

- selected items filtered or aggregated [p.279];
- their visual encoding changed [p.279];
- selected regions or items reordered within a view [p.279];
- a navigation trajectory built so the selected item is centred in the view at the end of an animated transition [p.279].
