# 11.7 Further Reading

## Sources by topic

- **Change.** An early paper argues for adding interaction support to previously static encoding idioms as a good starting point for thinking about views that change [Dix and Ellis 98] [p.286].
- **Animated transitions.** A taxonomy of animated transition types with design guidelines, and an empirical study showing strong evidence that properly designed transitions can improve graphical perception of changes [Heer and Robertson 07] [p.287].
- **Select.** *Selection: 524,288 Ways to Say "This Is Interesting"* argues for narrowing selection operations across linked views to a small set of combinations [Wills 96] [p.287].
- **Semantic zooming.** Pad++ was an early exploration [Bederson and Hollan 94]; LiveRAC is a more recent system using the idiom [McLachlan et al. 08] [p.287].
- **Constrained navigation.** Early work evangelised constrained navigation in 3D [Mackinlay et al. 90]; later work gives a framework for calculating smooth, efficient 2D panning and zooming trajectories [van Wijk and Nuij 03] [p.287].
