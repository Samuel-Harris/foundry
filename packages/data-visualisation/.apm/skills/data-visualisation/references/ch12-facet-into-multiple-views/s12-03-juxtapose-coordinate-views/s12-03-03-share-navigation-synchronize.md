# 12.3.3 Share Navigation: Synchronize

## Linked navigation

Views can also be coordinated by sharing navigation [p.301].

<!-- verbatim p.301 -->
> With linked navigation, moving the viewpoint in one view is synchronized to movement in the others.
<!-- /verbatim -->

Linked navigation is common in map views that pair a smaller bird's-eye overview window with a larger detail view, where interaction in the small window changes the viewpoint in the large one [p.301].
