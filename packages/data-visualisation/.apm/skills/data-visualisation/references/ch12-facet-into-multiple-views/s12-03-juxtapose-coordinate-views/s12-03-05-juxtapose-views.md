# 12.3.5 Juxtapose Views

## Two choices outside coordination

Two further choices about juxtaposition do not directly involve coordination: when to show each view and how to arrange them [p.303].

## When to show each view

The usual choice is that all views are permanently visible so users can glance between them, as the synonym side-by-side suggests. Another option is a view that temporarily pops up in response to a user action [p.303].

## How to arrange the views

Sometimes arrangement is not under the designer's control and is left to the window system on the user's computer; with many views, arranging them manually could be a burdensome load on the user [p.303].

<!-- verbatim p.303 -->
> A more sophisticated choice is to arrange the views themselves automatically, just like regions and items can be arranged.
<!-- /verbatim -->

Views can be aligned and ordered linearly in a list or two-dimensionally in a matrix, supporting higher-precision comparison than unaligned views. This is common when data is partitioned between the views [p.303].
