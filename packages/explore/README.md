# explore

Thorough read-only codebase search with cross-module reasoning.

## What it installs

| Primitive | Name      | Purpose                                               |
| --------- | --------- | ----------------------------------------------------- |
| Agent     | `explore` | Thorough codebase search with cross-module reasoning. |

## Install

```bash
apm install Samuel-Harris/foundry/packages/explore#v0.1.0 --target cursor,claude,copilot
```

## Targets

Deployed to `cursor`, `claude` and `copilot`.
