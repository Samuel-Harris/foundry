| --- | --- | --- |
| Agent | `architect` | Strategic architecture and debugging advisor. |

```bash
apm install Samuel-Harris/foundry/packages/foundry-architect#v0.1.0 --target cursor,claude,copilot
```

Deployed to `cursor`, `claude` and `copilot`.
