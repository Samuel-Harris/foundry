# foundry-handoff

Produce a handoff document that lets another agent or session continue the work.

## What it installs

| Primitive | Name | Purpose |
| --- | --- | --- |
| Skill | `handoff` | Create a comprehensive AI context handoff document for long-running sessions. |

## Install

```bash
apm install Samuel-Harris/foundry/packages/foundry-handoff#v0.1.0 --target cursor,claude,copilot
```

## Targets

Deployed to `cursor`, `claude` and `copilot`.
