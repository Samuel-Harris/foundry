# foundry-search

Search the codebase across git worktrees.

## What it installs

| Primitive | Name | Purpose |
| --- | --- | --- |
| Skill | `search-worktrees` | Find files, code, or content across all git worktrees of the current repository. |

## Install

```bash
apm install Samuel-Harris/foundry/packages/foundry-search#v0.1.0 --target cursor,claude,copilot
```

## Targets

Deployed to `cursor`, `claude` and `copilot`.
