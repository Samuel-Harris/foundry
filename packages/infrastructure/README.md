# infrastructure

AWS architecture diagrams rendered as Mermaid flowcharts.

## What it installs

| Primitive | Name | Purpose |
| --- | --- | --- |
| Skill | `aws-architecture-diagram` | Generate AWS architecture diagrams as Mermaid flowcharts with nested account/VPC subgraphs, numbered data-flow steps, and same-account placement. |

## Install

```bash
apm install Samuel-Harris/foundry/packages/infrastructure#v0.1.0 --target cursor,claude,copilot
```

## Targets

Deployed to `cursor`, `claude` and `copilot`.
