# ui

Remove machine-generated UI slop and restore visual quality.

## What it installs

| Primitive | Name | Purpose |
| --- | --- | --- |
| Skill | `uncodixify` | Guides UI design away from generic AI aesthetic patterns ("Codex UI") toward human-designed, functional interfaces inspired by Linear, Raycast, Stripe, and GitHub. |

## Install

```bash
apm install Samuel-Harris/foundry/packages/ui#v0.1.0 --target cursor,claude,copilot
```

## Targets

Deployed to `cursor`, `claude` and `copilot`.
